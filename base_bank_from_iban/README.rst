Automatically fills the bank name, BIC/SWIFT and country on bank
accounts from their IBAN using the bank registry provided by schwifty.

In Odoo 20, these details are stored directly on the bank account; there
is no separate bank record. Explicit values supplied when creating or
updating an account are preserved.

.. contents::
   :local:

Configuration
=============

No bank directory configuration is required. Bank details are obtained
from the schwifty registry.

Usage
=====

1. Open a contact and its bank accounts.
2. Create or edit an account and enter an IBAN.
3. The bank name, BIC/SWIFT and country are filled automatically.

This also applies when creating or updating accounts through imports or
the API, and when using the manual bank setup wizard. If a valid IBAN
has no bank in the registry, only its country can be identified.
