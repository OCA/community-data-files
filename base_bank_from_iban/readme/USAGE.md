To use this module, you need to:

1.  Go to Partner
2.  Click *Bank Account(s)* in "Invoicing" page.
3.  Create/modify IBAN bank account.
4.  When you put the bank account number, the bank is selected if a bank
    with the same country and code already exists.
5.  When saving, if no bank is set yet, it is filled from the bank
    registry and created if needed.
