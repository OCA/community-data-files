## 19.0.1.0.0 (2026-05-12)

- Initial release. Ships the abstract ``uom.preset`` model with two
  vocabularies:

  - ``pricat`` (Dutch B2B), sourced from INDI's public OCI-PunchOut
    documentation.
  - ``x12_355`` (ANSI ASC X12 element 355, US retail/manufacturing
    EDI), sourced from the public Ariba Network ANSI X12 ↔ UNUOM
    mapping (SAP, 2014).
